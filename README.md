# 1/f Noise Analysis in Graphene Samples

## Project Overview

This project was developed during a summer internship and focuses on the analysis and characterization of 1/f noise in graphene-based devices using MATLAB. The objective was to investigate the spectral properties of noise signals and understand their behavior through signal processing and statistical analysis techniques.

## Objectives

- Analyze low-frequency 1/f noise in graphene samples.
- Study the spectral characteristics of measured signals.
- Perform frequency-domain analysis using MATLAB.
- Extract and evaluate noise-related parameters.
- Support research into graphene device performance and reliability.

## Technologies Used

- MATLAB
- Signal Processing Toolbox
- FFT Analysis
- Statistical Analysis
- Data Visualization

## Methodology

1. Import and preprocess experimental data.
2. Remove noise artifacts and outliers where necessary.
3. Perform frequency-domain analysis using Fast Fourier Transform (FFT).
4. Compute Power Spectral Density (PSD).
5. Identify and characterize 1/f noise behavior.
6. Generate plots and visualizations for interpretation.

## Key Features

- Automated MATLAB-based analysis workflow.
- Frequency spectrum visualization.
- Power Spectral Density calculations.
- Statistical characterization of noise signals.
- Research-oriented data interpretation.

## Results

The project enabled the analysis of low-frequency noise characteristics in graphene devices and provided insights into noise behavior across different operating conditions. MATLAB-based processing facilitated efficient visualization and interpretation of experimental measurements.
